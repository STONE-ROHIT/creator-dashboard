# Creator Dashboard

A full-stack platform for content creators to monetize their content.

## Project Structure

- `/server` - Node.js + Express backend
- `/client` - React frontend

## Getting Started

### Backend
```bash
cd server
npm install
cp .env.example .env
# Edit .env with your database credentials
npm start
```

### Frontend
```bash
cd client
npm install
npm start
```

## Tech Stack
- Frontend: React, Tailwind CSS
- Backend: Node.js, Express
- Database: PostgreSQL
- Auth: JWT
- Payments: Razorpay (test mode)
